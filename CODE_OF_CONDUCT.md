# Code de conduite / Code of Conduct

## Français

Ce projet suit le **Contributor Covenant v2.1**.

- Soyez respectueux : pas d’attaque personnelle, pas de propos discriminatoire.
- Critiquez le code, pas la personne.
- Signalez tout comportement inacceptable au propriétaire du dépôt.

Les mainteneurs peuvent modifier ou retirer une contribution, et exclure un
participant, en cas de manquement.

Texte de référence : <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## English

This project follows the **Contributor Covenant v2.1**. Be respectful, critique
code rather than people, and report unacceptable behaviour to the repository
owner. Maintainers may edit or remove contributions and exclude participants.

Reference: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
